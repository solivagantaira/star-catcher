# Star Catcher

A simple browser arcade game made with HTML, CSS, and JavaScript.

## Play locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Create a public GitHub repository named `star-catcher`.
2. Upload `index.html` and `README.md` to the repository root on the `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then **Save**.
6. Find the live URL under **Settings → Pages**.

## Privacy

The game is a static site and needs no server or account. A high score, if enabled in the game, is stored in the player's browser.
